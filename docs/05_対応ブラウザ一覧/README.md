## 運用ルール

- 各PCブラウザの最新安定版での利用を想定。
- セキュリティ更新が適用されていない他ブラウザは、サポート対象外とします。
- Windows版Safariは動作確認とサポートの対象外です。
- ブラウザのメジャーバージョン更新時、または少なくとも3か月ごとに内容を見直します。
