# Verification 画面設計書

Verification の画面設計書です。

## 画面デザイン

- [Figma（※ ダミー）](https://)

<br />

## 画面項目

#### ヘッダー

| 項目名       | 説明                                           | 備考 |
| ------------ | ---------------------------------------------- | ---- |
| 共通ヘッダー | Auth 画面用の nav リストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名               | 説明                                                                                                                           | 備考             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------- |
| 画面タイトル         | 「Verification」のテキスト。                                                                                                   |                  |
| 処理エラーメッセージ | Verify 処理失敗時にエラーメッセージを表示する。                                                                                | 通常時は非表示。 |
| 成功メッセージ       | Verify 処理成功時に「Verify 完了、Sign In できるよ！」を表示する。                                                             | 通常時は非表示。 |
| verificationCode     | メールで通知された確認コードのインプット項目。入力値はマスク表示する。<br />未入力時にエラー文言「必須項目だよ。」を表示する。 | 必須項目。       |
| email                | Sign Up に使用したメールアドレスのインプット項目。<br />未入力時にエラー文言「必須項目だよ。」を表示する。                     | 必須項目。       |
| リセットボタン       | フォームの入力値、処理エラーメッセージおよび成功メッセージをリセットするボタン。                                               |                  |
| 送信するボタン       | 入力した確認コードとメールアドレスで Verify を実行するボタン。                                                                 |                  |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |
