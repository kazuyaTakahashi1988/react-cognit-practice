## 画面項目

#### ヘッダー

| 項目名       | 説明                                              | 備考 |
| ------------ | ------------------------------------------------- | ---- |
| 共通ヘッダー | Example 画面用の nav リストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名       | 説明                        | 備考 |
| ------------ | --------------------------- | ---- |
| 画面タイトル | 「TodoExample」のテキスト。 |      |

<br />

| 項目名                | 説明                                                                                               | 備考       |
| --------------------- | -------------------------------------------------------------------------------------------------- | ---------- |
| 追加ボタン            | 未完了かつタスクが空の Todo を末尾に1行追加するボタン。                                            |            |
| Todo リスト           | Todo を複数行入力するリスト。初期状態およびリセット後は1行表示する。送信時にバリデーションを行う。 |            |
| ー チェックボックス   | チェックボックス項目。                                                                             |            |
| ー テキストインプット | テキストインプット項目。<br />バリデーション内容「未入力」でエラー文言「必須項目だよ。」表示。     | 必須項目。 |
| ー 削除ボタン         | Todo リストを1行削除するボタン。<br />Todo リストが1行しかない場合は非活性。                       |            |
| リセットボタン        | Todo リストを初期の1行に戻し、入力値とバリデーションエラーをリセットするボタン。                   |            |
| 送信するボタン        | バリデーション正常時に Todo リストの内容をコンソールへ出力するボタン。                             |            |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |
