## 画面項目

#### ヘッダー

| 項目名       | 説明                                              | 備考 |
| ------------ | ------------------------------------------------- | ---- |
| 共通ヘッダー | Example 画面用の nav リストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名       | 説明                                         | 備考 |
| ------------ | -------------------------------------------- | ---- |
| 画面タイトル | 画面タイトル（サブタイトル含む）のテキスト。 |      |

<br />

| 項目名                | 説明                                                                                                                             | 備考                |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| 追加ボタン            | 未完了かつタスクが空の Todo を末尾に1行追加するボタン。                                                                          |                     |
| Todo リスト           | 送信時にバリデーションを行う。エラー発生後は入力値の変更ごとにバリデーションを再検証し、正常になった項目のエラー表示を解消する。 | 初期状態は1行表示。 |
| ー チェックボックス   | チェックボックス項目。 タスク完了（true）・未完了（false）を表す。                                                               |                     |
| ー テキストインプット | テキストインプット項目。<br />未入力の場合にエラー文言「必須項目だよ。」を表示する。                                             | 必須項目。          |
| ー 削除ボタン         | Todo リストを1行削除するボタン。<br />Todo リストが1行しかない場合は非活性。                                                     |                     |
| リセットボタン        | Todo リストを1行に戻し、全入力値とバリデーションエラーを初期化するボタン。                                                       |                     |
| 送信するボタン        | バリデーションを行い、正常なら Todo リストの内容をコンソールへ出力するボタン。                                                   |                     |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |
