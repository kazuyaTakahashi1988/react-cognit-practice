## 画面項目

#### ヘッダー

| 項目名       | 説明                                            | 備考 |
| ------------ | ----------------------------------------------- | ---- |
| 共通ヘッダー | Example 画面用のnavリストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名       | 説明                                   | 備考 |
| ------------ | -------------------------------------- | ---- |
| 画面タイトル | 画面タイトルとサブタイトルのテキスト。 |      |

<br />

| 項目名                | 説明                                                                                                                                                                                                                        | 備考 |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 追加ボタン            | Todo リストを1行追加するボタン。                                                                                                                                                                                            |      |
| Todo リスト           | フロント側での送信時バリデーションあり。<br />バリデーションエラー発生時、各エラー対象項目リアルタイムインプットで正しい値か判定 → 正ならエラー文言の表示解消。<br />リストは最低でも1行表示される（0行になることはない）。 |      |
| ー チェックボックス   | チェックボックス項目。                                                                                                                                                                                                      |      |
| ー テキストインプット | テキストインプット項目。<br />バリデーション内容「未入力」でエラー文言「必須項目だよ。」表示。                                                                                                                              |      |
| ー 削除ボタン         | Todo リストを1行削除するボタン。<br />Todo リストが1行しかない場合は非活性。                                                                                                                                                |      |
| リセットボタン        | Todo リストの値・追加された行をリセットするボタン。                                                                                                                                                                         |      |
| 送信するボタン        | Todo リストの内容を送信するボタン。                                                                                                                                                                                         |      |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |
