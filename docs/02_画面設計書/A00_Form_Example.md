#### コンテンツ

| 項目名       | 説明                                               | 備考 |
| ------------ | -------------------------------------------------- | ---- |
| 画面タイトル | 「FormExample」と「：react-hook-form」のテキスト。 |      |

<br />

| 項目名                  | 説明                                                                                                                                                                | 備考          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| 各入力フォーム          | 送信時にバリデーションを行う。エラー発生後は入力値の変更時に再検証し、正常になった項目のエラー文言を非表示にする。                                                  | 全項目必須。  |
| ー お名前               | テキストインプット項目。<br />未入力、2文字未満、51文字以上の場合に、それぞれ「必須項目だよ。」「2文字以上にしてね」「最大50文字だよ」を表示する。                  |               |
| ー よく視聴するジャンル | アクション、コメディ、ドラマから選択するチェックボックス項目。<br />未選択または選択数が2つ未満の場合に「必須項目だよ。」「２つ以上選択してください。」を表示する。 | 2つ以上選択。 |
| ー お問い合わせ方法     | ラジオボタン項目。<br />バリデーション内容「未チェック」でエラー文言「必須項目だよ。」表示。                                                                        |               |
| ー お支払い方法         | スイッチボタン（ラジオボタン）項目。 <br />バリデーション内容「未チェック」でエラー文言「必須項目だよ。」表示。                                                     |               |
| ー テーマ色の選択       | セレクトボックス項目。 <br />バリデーション内容「未選択」でエラー文言「必須項目だよ。」表示。                                                                       |               |
| ー 都道府県             | セレクトカスタムボックス項目。 <br />バリデーション内容「未選択」でエラー文言「必須項目だよ。」表示。                                                               |               |
| ー ご相談の内容         | テキストエリア項目 。<br />バリデーション内容「未入力 / 2文字以下 / 50文字以上」でエラー文言「必須項目だよ。/ 2文字以上にしてね / 最大50文字だよ」表示。            |               |
| リセットボタン          | 全入力値とバリデーションエラーを初期状態に戻すボタン。                                                                                                              |               |
| 送信するボタン          | バリデーション正常時にフォーム内容をテスト用APIへ送信するボタン。                                                                                                   |               |
