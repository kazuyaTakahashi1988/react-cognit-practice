# Sign Up 画面設計書

Sign Up の画面設計書です。

<br />

## 画面デザイン

- [Figma（※ ダミー）](https://)

<br />

## 画面項目

#### ヘッダー

| 項目名       | 説明                                           | 備考 |
| ------------ | ---------------------------------------------- | ---- |
| 共通ヘッダー | Auth 画面用の nav リストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名               | 説明                                                                                                         | 備考             |
| -------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------- |
| 画面タイトル         | 「SignUp」のテキスト。                                                                                       |                  |
| 処理エラーメッセージ | Sign Up 処理失敗時にエラーメッセージを表示する。                                                             | 通常時は非表示。 |
| 成功メッセージ       | Sign Up 処理成功時に、Verification の要否に応じた案内メッセージを表示する。                                  | 通常時は非表示。 |
| email                | メールアドレスのインプット項目。<br />未入力時にエラー文言「必須項目だよ。」を表示する。                     | 必須項目。       |
| password             | パスワードのインプット項目。入力値はマスク表示する。<br />未入力時にエラー文言「必須項目だよ。」を表示する。 | 必須項目。       |
| リセットボタン       | フォームの入力値、処理エラーメッセージおよび成功メッセージをリセットするボタン。                             |                  |
| 送信するボタン       | 入力したメールアドレスとパスワードで Sign Up を実行するボタン。                                              |                  |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |

<br />

## 備考

- 未認証ユーザーのみアクセス可能な画面。
- パス：`/auth/signup`
