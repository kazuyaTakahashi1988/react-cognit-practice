# Sign Up 画面設計書

Sign Up の画面設計書です。

<br />

## 画面デザイン

- [Figma（※ ダミー）](https://)

<br />

## 画面項目

#### ヘッダー

| 項目名       | 説明                                           | 備考 |
| ------------ | ---------------------------------------------- | ---- |
| 共通ヘッダー | Auth 画面用の nav リストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名       | 説明                                         | 備考 |
| ------------ | -------------------------------------------- | ---- |
| 画面タイトル | 画面タイトル（サブタイトル含む）のテキスト。 |      |

<br />

| 項目名               | 説明                                                                        | 備考             |
| -------------------- | --------------------------------------------------------------------------- | ---------------- |
| 処理エラーメッセージ | Sign Up 処理失敗時にエラーメッセージを表示する。                            | 通常時は非表示。 |
| 成功メッセージ       | Sign Up 処理成功時に、Verification の要否に応じた案内メッセージを表示する。 | 通常時は非表示。 |

<br />

| 項目名         | 説明                                                                                                                             | 備考       |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| 各入力フォーム | 送信時にバリデーションを行う。エラー発生後は入力値の変更ごとにバリデーションを再検証し、正常になった項目のエラー表示を解消する。 |            |
| ー email       | メールアドレスのインプット項目。<br />未入力の場合にエラー文言「必須項目だよ。」を表示する。                                     | 必須項目。 |
| ー password    | パスワードのインプット項目。入力値はマスク表示する。<br />未入力の場合にエラー文言「必須項目だよ。」を表示する。                 | 必須項目。 |
| リセットボタン | 全入力値とバリデーションエラー、処理エラー/成功メッセージを初期化するボタン。                                                    |            |
| 送信するボタン | バリデーションを行い、正常なら入力したメールアドレスとパスワードで Sign Up を実行するボタン。                                    |            |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |

<br />

## 備考

- 未認証ユーザーのみアクセス可能な画面。
- パス：`/auth/signup`
