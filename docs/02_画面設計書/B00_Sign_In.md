# Sign In 画面設計書

Sign In の画面設計書です。

<br />

## 画面デザイン

- [Figma（※ ダミー）](https://)

<br />

## 画面項目

#### ヘッダー

| 項目名       | 説明                                           | 備考 |
| ------------ | ---------------------------------------------- | ---- |
| 共通ヘッダー | Auth 画面用の nav リストが並んだ共通ヘッダー。 |      |

#### コンテンツ

| 項目名               | 説明                                                                                                         | 備考             |
| -------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------- |
| 画面タイトル         | 「SignIn」のテキスト。                                                                                       |                  |
| 処理エラーメッセージ | Sign In 処理失敗時、または追加の Verification が必要な場合にメッセージを表示する。                           | 通常時は非表示。 |
| email                | メールアドレスのインプット項目。<br />未入力時にエラー文言「必須項目だよ。」を表示する。                     | 必須項目。       |
| password             | パスワードのインプット項目。入力値はマスク表示する。<br />未入力時にエラー文言「必須項目だよ。」を表示する。 | 必須項目。       |
| リセットボタン       | フォームの入力値と処理エラーメッセージをリセットするボタン。                                                 |                  |
| 送信するボタン       | 入力したメールアドレスとパスワードで Sign In を実行するボタン。                                              |                  |

#### フッター

| 項目名       | 説明                     | 備考 |
| ------------ | ------------------------ | ---- |
| 共通フッター | 全画面用の共通フッター。 |      |

<br />
