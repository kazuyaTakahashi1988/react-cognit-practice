# Dropdown Menu Example 詳細設計書

Dropdown Menu Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名         | 説明                                                                           | 備考 |
| -------------- | ------------------------------------------------------------------------------ | ---- |
| メニュー初期化 | A～D の各メニューに、識別子付きの3項目と項目ごとのクリックイベントを設定する。 |      |

#### イベント操作時

| 項目名               | 説明                                                                                | 備考             |
| -------------------- | ----------------------------------------------------------------------------------- | ---------------- |
| 各メニューボタン押下 | 対象のメニューリストの表示・非表示を切り替える。                                    |                  |
| 各メニュー項目押下   | メニュー識別子（A～D）と項目番号（01～03）に対応するメッセージを alert で表示する。 | サンプル用処理。 |

<br />

## 備考

- メニュー A・C は左寄せ、B・D は右寄せで表示する。
