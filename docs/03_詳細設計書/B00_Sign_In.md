# Sign In 詳細設計書

Sign In の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名           | 説明                                                                                   | 備考                         |
| ---------------- | -------------------------------------------------------------------------------------- | ---------------------------- |
| 認証状態チェック | 認証状態の確認中は確認メッセージを表示する。認証済みの場合は Sign Out 画面へ遷移する。 | 未認証の場合のみ画面を表示。 |
| フォーム初期化   | email、password を初期化する。                                                         |                              |

#### イベント操作時

| 項目名             | 説明                                                                                                                                                                                 | 備考 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| リセットボタン押下 | email、password の入力値、バリデーションエラーおよび処理エラーメッセージをリセットする。                                                                                             |      |
| 送信するボタン押下 | email、password の必須バリデーションを行う。正常時はローディング表示を開始し、AWS Amplify Auth の Sign In 処理を実行する。処理終了時は成功・失敗を問わずローディング表示を終了する。 |      |
| ー Sign In 成功    | 認証状態を再取得する。認証済みとなった場合、画面のアクセス制御により Sign Out 画面へ遷移する。                                                                                       |      |
| ー 追加認証が必要  | フォームをリセットし、「Sign In にはまだ追加手順（Verify）が必要だよ！」を表示する。                                                                                                 |      |
| ー Sign In 失敗    | AWS Amplify Auth から取得したエラーメッセージを表示する。Error オブジェクトを取得できない場合は「Sign In に失敗したよ...」を表示する。                                               |      |

<br />

## 備考

- AWS Cognito のユーザー名には入力された email を使用する。
