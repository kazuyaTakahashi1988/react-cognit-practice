# Store Example 詳細設計書

Store Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名                   | 説明                                                                      | 備考 |
| ------------------------ | ------------------------------------------------------------------------- | ---- |
| ストア値の取得および出力 | ストアから exampleString / exampleFlag の値を取得し、出力箇所に表示する。 |      |

#### イベント操作時

| 項目名                             | 説明                                                                                                  | 備考 |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------- | ---- |
| テキストインプット入力             | インプットごとに exampleString のストア値が更新される。<br />また出力箇所に値（文字列）が表示される。 |      |
| スイッチボタン（ラジオボタン）押下 | 押下ごとに exampleFlag のストア値が更新される。<br />また出力箇所に値（真偽値）が表示される。         |      |
