# Store Example 詳細設計書

Store Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名                   | 説明                                                                                                                                                | 備考 |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| ストア値の取得および出力 | Redux ストアから exampleString と exampleFlag を取得する。exampleString は文字列、exampleFlag は「true」または「false」として各出力箇所に表示する。 |      |

#### イベント操作時

| 項目名                 | 説明                                                                                                                    | 備考                              |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| テキストインプット入力 | 入力値の変更ごとに exampleStringSet を dispatch して exampleString を更新する。更新後の文字列を出力箇所に反映する。     |                                   |
| スイッチボタン変更     | checked の変更ごとに exampleFlagSet を dispatch して exampleFlag を更新する。更新後の真偽値と対応するラベルを表示する。 | false：noActive<br />true：Active |

<br />

## 備考

- Redux Toolkit のストア更新と React Redux の `useSelector` による再描画を確認するためのサンプル。
