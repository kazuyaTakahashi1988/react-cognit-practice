# Todo Example 詳細設計書

Todo Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名         | 説明                                                       | 備考 |
| -------------- | ---------------------------------------------------------- | ---- |
| フォーム初期化 | taskList を、未完了かつタスクが空の Todo 1件で初期化する。 |      |

#### イベント操作時

| 項目名                | 説明                                                                     | 備考                             |
| --------------------- | ------------------------------------------------------------------------ | -------------------------------- |
| 追加ボタン押下        | taskList の末尾に、未完了かつタスクが空の Todo を1件追加する。           |                                  |
| 削除ボタン押下        | ボタンの data-index に対応する Todo を taskList から削除する。           | Todo が1件の場合はボタン非活性。 |
| リセットボタン押下    | taskList を初期の1件に戻し、入力値とバリデーションエラーをリセットする。 |                                  |
| 送信するボタン押下    | 各 Todo のタスクに対して必須バリデーションを検証する。                   |                                  |
| ー バリデーション成功 | 完了状態とタスクを含む taskList の内容をブラウザのコンソールへ出力する。 | サンプル用処理。                 |

<br />

## 備考

- React Hook Form の `useFieldArray` を使用して Todo の追加・削除を行う。
