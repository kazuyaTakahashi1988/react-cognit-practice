#### イベント操作時

| 項目名             | 説明                                                                          | 備考 |
| ------------------ | ----------------------------------------------------------------------------- | ---- |
| 追加ボタン押下     | Todo リストが1行追加される。                                                  |      |
| 削除ボタン押下     | Todo リストが1行削除される。                                                  |      |
| リセットボタン押下 | Todo リストの値とエラー文言・追加された行がリセット・非表示・削除となる。     |      |
| 送信するボタン押下 | バリデーションが通れば、Todo リストの送信内容がコンソール画面で出力される。　 |      |
