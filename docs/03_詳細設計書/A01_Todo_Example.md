# Todo Example 詳細設計書

Todo Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名         | 説明                                                               | 備考 |
| -------------- | ------------------------------------------------------------------ | ---- |
| フォーム初期化 | 全入力値とバリデーションエラーを初期化し、Todo を1行の状態にする。 |      |

#### イベント操作時

| 項目名                | 説明                                                                       | 備考                                   |
| --------------------- | -------------------------------------------------------------------------- | -------------------------------------- |
| 追加ボタン押下        | Todo リストの末尾に、未完了かつタスクが空の Todo を1行追加する。           |                                        |
| 削除ボタン押下        | ボタン行に対応する Todo を Todo リストから削除する。                       | Todo リストが1行の場合はボタン非活性。 |
| リセットボタン押下    | Todo リストを初期の1行に戻し、全入力値とバリデーションエラーを初期化する。 |                                        |
| 送信するボタン押下    | 必須項目のバリデーションを行う。                                           |                                        |
| ー バリデーション成功 | Todo リストの内容をブラウザのコンソールへ出力する。                        | サンプル用処理。                       |

<br />

## 備考

- React Hook Form の `useFieldArray` を使用して Todo の追加・削除を行う。
