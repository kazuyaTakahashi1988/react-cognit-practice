# Sign Up 詳細設計書

Sign Up の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名           | 説明                                                                                   | 備考                         |
| ---------------- | -------------------------------------------------------------------------------------- | ---------------------------- |
| 認証状態チェック | 認証状態の確認中は確認メッセージを表示する。認証済みの場合は Sign Out 画面へ遷移する。 | 未認証の場合のみ画面を表示。 |
| フォーム初期化   | 全入力値とバリデーションエラー、処理エラー/成功メッセージを初期化する。                |                              |

#### イベント操作時

| 項目名             | 説明                                                                                                                                                                                                             | 備考 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| リセットボタン押下 | 全入力値とバリデーションエラー、処理エラー/成功メッセージを初期化する。                                                                                                                                          |      |
| 送信するボタン押下 | 必須項目のバリデーションを行う。正常時はローディング表示を開始し、AWS Amplify Auth の Sign Up 処理を実行する。email は Cognito のユーザー名および email 属性に設定する。処理終了時はローディング表示を終了する。 |      |
| ー Sign Up 成功    | フォームとメッセージをリセットする。Verification が不要な場合は「Sign Up 成功! Sign In しよう！」、必要な場合は「OK！ Verify用のコードをメールで送ったから確認してね！」を表示する。                             |      |
| ー Sign Up 失敗    | AWS Amplify Auth から取得したエラーメッセージを表示する。Error オブジェクトを取得できない場合は「Sign Up に失敗したよ...」を表示する。                                                                           |      |

<br />

## 備考

- Sign Up 成功後の画面遷移は行わず、後続操作を成功メッセージで案内する。
