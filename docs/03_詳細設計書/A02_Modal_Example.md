# Modal Example 詳細設計書

Modal Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名         | 説明                                                | 備考 |
| -------------- | --------------------------------------------------- | ---- |
| 表示状態初期化 | モーダル - 01、モーダル - 02 をともに非表示とする。 |      |

#### イベント操作時

| 項目名                     | 説明                                                                             | 備考                                          |
| -------------------------- | -------------------------------------------------------------------------------- | --------------------------------------------- |
| モーダルを開く01ボタン押下 | モーダル - 01 の表示状態を true にし、ダイアログを表示する。                     |                                               |
| モーダルを開く02ボタン押下 | モーダル - 02 の表示状態を true にし、長文コンテンツを持つダイアログを表示する。 |                                               |
| イベント01ボタン押下       | 「01 onEvent !!」の alert を表示する。                                           | サンプル用処理。                              |
| イベント02ボタン押下       | 「02 onEvent !!」の alert を表示する。                                           | サンプル用処理。                              |
| 閉じる操作                 | 対象モーダルの表示状態を false にして閉じる。                                    | 閉じるボタン、「×」およびモーダル背景を含む。 |

<br />

## 備考

- 2つのモーダルの表示状態は個別に管理する。
