# Sign Out 詳細設計書

Sign Out の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名           | 説明                                                                                | 備考                           |
| ---------------- | ----------------------------------------------------------------------------------- | ------------------------------ |
| 認証状態チェック | 認証状態の確認中は確認メッセージを表示する。未認証の場合は Sign In 画面へ遷移する。 | 認証済みの場合のみ画面を表示。 |

#### イベント操作時

| 項目名              | 説明                                                                                                                                                                 | 備考 |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| Sign Out ボタン押下 | ローディング表示を開始し、処理エラーメッセージをリセットして AWS Amplify Auth の Sign Out 処理を実行する。処理終了時は成功・失敗を問わずローディング表示を終了する。 |      |
| ー Sign Out 成功    | 認証状態を再取得する。未認証となった場合、画面のアクセス制御により Sign In 画面へ遷移する。                                                                          |      |
| ー Sign Out 失敗    | AWS Amplify Auth から取得したエラーメッセージを表示する。Error オブジェクトを取得できない場合は「Sign Out に失敗したよ...」を表示する。                              |      |

<br />

## 備考

- Sign Out は現在のセッションを対象とする。
