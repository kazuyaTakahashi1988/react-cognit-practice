# Accordion Example 詳細設計書

## 詳細項目

#### アクセス時

| 項目名         | 説明                                             | 備考 |
| -------------- | ------------------------------------------------ | ---- |
| 表示状態初期化 | 1つ目を閉じた状態、2つ目を開いた状態で表示する。 |      |

#### イベント操作時

| 項目名                       | 説明                                                                         | 備考 |
| ---------------------------- | ---------------------------------------------------------------------------- | ---- |
| 各アコーディオンタイトル押下 | 対象コンテンツの表示・非表示を切り替える。開閉状態は各項目で個別に管理する。 |      |
