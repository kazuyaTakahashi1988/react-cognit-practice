# Form Example 詳細設計書

Form Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名         | 説明                                                                       | 備考 |
| -------------- | -------------------------------------------------------------------------- | ---- |
| フォーム初期化 | name、inquiry、payment、theme、address、description、genres を初期化する。 |      |

#### イベント操作時

| 項目名                | 説明                                                                                                                                              | 備考 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| リセットボタン押下    | 全入力値を初期値に戻し、バリデーションエラーを非表示にする。                                                                                      |      |
| 送信するボタン押下    | 全項目の必須バリデーションを検証する。                                                                                                            |      |
| ー バリデーション成功 | フォーム内容を testPostApi（テスト用POST API）へ送信する。レスポンスが正常（HTTP 200）でない場合は 500 Internal Server Error 画面へ置換遷移する。 |      |

<br />

## 備考

- testPostApi はエラー処理と 500 画面への遷移を確認するためのテスト用API。
