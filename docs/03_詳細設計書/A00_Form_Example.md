# Form Example 詳細設計書

Form Example の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名         | 説明                                         | 備考 |
| -------------- | -------------------------------------------- | ---- |
| フォーム初期化 | 全入力値とバリデーションエラーを初期化する。 |      |

#### イベント操作時

| 項目名                | 説明                                                                                                                                                    | 備考 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| リセットボタン押下    | 全入力値とバリデーションエラーを初期化する。                                                                                                            |      |
| 送信するボタン押下    | 必須項目のバリデーションを行う。                                                                                                                        |      |
| ー バリデーション成功 | フォーム内容を testPostApi（テスト用POST API）へ送信する。<br />レスポンスが正常（HTTP 200）でない場合は 500 Internal Server Error 画面へ置換遷移する。 |      |

<br />

## 備考

- testPostApi はエラー処理と 500 画面への遷移を確認するためのテスト用API。
