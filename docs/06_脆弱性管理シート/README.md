## 更新ルール

- 依存モジュールの追加・更新時、または定期的に同じ条件で監査を実施します。
- 脆弱性が検出された場合は、モジュール名、影響バージョン、深刻度、脆弱性ID、概要、対応状況を追記します。
- バージョンは `yarn.lock` とインストール状態を基準とし、再監査時に一覧を更新します。
